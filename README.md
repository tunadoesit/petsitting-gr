# Kypseli Pet Sitting

A premium one-page pet sitting website for Melissanthi Kontoleon, based in Athens, Greece. Built with Next.js and designed to feel warm, editorial, and trustworthy.

## Tech stack

- Next.js 14
- React 18
- TypeScript
- CSS Modules-free global styling with a custom visual system

## Local development

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Open http://localhost:3000

## Production build

npm run build

## Start production server

npm run start

## Deployment on Vercel

1. Push this repository to GitHub.
2. Import the project into Vercel.
3. Use the default Next.js settings.
4. Deploy.

## Notes

- The contact form is a front-end placeholder for V1 and can later be connected to a booking workflow or calendar integration.
- The WhatsApp and email details are placeholders for future setup.
